## What I build

Most websites fail basic accessibility. Not because developers don't care, but because accessibility is easy to get wrong and hard to test manually. I build tools that make it easier to find, fix, and prevent those failures.

**[A11Y Lead Engine](https://github.com/mikko-lab/a11y-lead-engine)** — Automated WCAG 2.2 AA scanner for WordPress sites. Scans domains, generates AI summaries in Finnish, enriches with YTJ/Kauppalehti business data, and sends personalized outreach emails. Integrates Finlex + Rechtspraak legal case data for sales context.

**[WPSA Booking](https://github.com/mikko-lab/wpsa-booking)** — Accessible WordPress booking plugin with zero-click calendar sync. Creates Google Meet or Teams links automatically, sends calendar invites, prevents double-bookings with timeslot locking. WCAG 2.2 AA compliant — real `<button>` elements, not `<div onClick>` hacks.

**[AAFT](https://github.com/mikko-lab/aaft)** — React component library for accessible admin interfaces. Forms, data tables, modals, and an audit tool — all WCAG 2.2 AA compliant, screen reader tested, keyboard navigable.

**[Luukku AI](https://github.com/mikko-lab/luukku-ai)** — Upload a Finnish housing company document (isännöitsijäntodistus), get an AI risk assessment in seconds. Classifies renovations, calculates risk score 0–10, outputs a verdict: buy / consider carefully / avoid.

**[GEO Agent](https://github.com/mikko-lab/geo-agent)** — WordPress content optimizer for AI-powered search (ChatGPT, Perplexity, Google AI Overviews). Human-in-the-loop: suggests improvements, waits for approval before publishing.
