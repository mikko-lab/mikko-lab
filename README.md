## What I build

**[A11Y Lead Engine](https://github.com/mikko-lab/a11y-lead-engine)** — AI-driven accessibility auditing pipeline. Scans WordPress sites for WCAG 2.2 AA violations, generates LLM-powered audit summaries in Finnish, enriches leads with YTJ/Kauppalehti business data, and sends personalized outreach emails. Integrates Finlex + Rechtspraak legal case data for sales context.

**[WPSA Booking](https://github.com/mikko-lab/wpsa-booking)** — Event-driven booking automation with OAuth integrations. Creates Google Meet or Teams links automatically via API, sends calendar invites, prevents double-bookings with timeslot locking. Zero manual steps from booking to confirmed meeting.

**[Luukku AI](https://github.com/mikko-lab/luukku-ai)** — LLM-powered document intelligence for financial risk analysis. Upload a Finnish housing company document (isännöitsijäntodistus), get a structured risk assessment in seconds. Classifies renovation types, calculates risk score 0–10, outputs a verdict: buy / consider carefully / avoid.

**[GEO Agent](https://github.com/mikko-lab/geo-agent)** — Generative Engine Optimization system for WordPress. Optimizes content for AI-powered search (ChatGPT, Perplexity, Google AI Overviews). Human-in-the-loop: suggests improvements, waits for approval before publishing.

**[AAFT](https://github.com/mikko-lab/aaft)** — React component library for accessible admin interfaces. Forms, data tables, modals, and an audit tool — WCAG 2.2 AA compliant, screen reader tested, keyboard navigable.
